## Fails (actionable)

### ❌ 5.3 — No timeout on Anthropic API calls

**Risk:** High. If the Anthropic API hangs, the background synthesis promise in `zug_end_session` leaks indefinitely. The MCP response returns immediately (synthesis is async), but the Node process holds an open handle that never resolves.

**Location:** `src/synthesize.ts` — `client.messages.create()`

**Fix:** Add `AbortController` with a 30-second timeout.

**Status:** Fixed 2026-05-23 (see git log)

---

### ❌ 4.5 — No retry on Anthropic API calls

**Risk:** Medium. Transient API errors (rate limits, 529, network blips) cause silent synthesis failure with no recovery. The error is now logged (ISS-002 fix), but there's no retry path.

**Location:** `src/synthesize.ts` — `client.messages.create()`

**Fix:** 1 retry after 2s on transient errors (5xx, network errors). No retry on 4xx (bad request, auth).

**Status:** Fixed 2026-05-23 (see git log)

---

### ❌ 3.15 — No SAST/security gates in CI

**Risk:** Low for a personal tool. No user-facing attack surface via stdio. HTTP transport has PKCE + rate limiting.

**Fix:** Add `pnpm audit` to CI as a lightweight substitute. Full SAST (CodeQL, Semgrep) is overkill for this scope.

**Status:** Deferred — acceptable for personal tool. Revisit if HTTP transport becomes publicly exposed.

---

### ❌ 9.4 — No Architecture Decision Records (ADRs)

**Risk:** Low. Key decisions are documented in handovers and the session comparison doc, but not in a discoverable ADR format. New contributors (or future-you after a long gap) can't find the reasoning.

**Fix:** Create `docs/adr/` with ADRs for the three most consequential decisions made.

**Status:** Fixed 2026-05-23 (see git log)

## Partials (noted, not blocking)

### ⚠️ 1.2 — Threat model informal

OAuth `/register` open endpoint (ISS-013) — accepted. PKCE prevents token theft; personal tool has no sensitive user data. No formal STRIDE model but risk documented.

### ⚠️ 2.3 — Multi-step writes not atomic

`zug_end_session` writes session log then appends to PERSONA.md sequentially. A crash between writes leaves inconsistent state. ISS-019 — accepted for single user. Session files are recoverable source of truth.

### ⚠️ 2.9 — Full JSONL scan for session filter

`getObservationsBySession()` reads all of `observations.jsonl` to filter by session ID. At current growth rate (~5 obs/session × 60 sessions = ~300 lines) this is fast. Degrades past ~5k observations. No fix needed now.

### ⚠️ 6.4 — Synchronous file reads on MCP request thread

`zug_get_context` uses `readFileSync` for PERSONA (12KB) and PLAYBOOK (5KB). Acceptable now. Will degrade if PERSONA grows past ~100KB. Revisit if sessions/week increases significantly.

### ⚠️ 9.1 — ZUG_DATA_DIR path duplicated

`getPaths()` in `storage.ts`, `loadApiKey()` in `api-key.ts`, and `synthesize-cli.ts` all compute the base dir from `ZUG_DATA_DIR`. ISS-009 tracks this. Deferred.

### ⚠️ Architecture.md stale

Says "Phase 2: Haiku Synthesis — when implemented" but synthesis has been live since p4. Fixed 2026-05-23.
